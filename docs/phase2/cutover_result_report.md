## 6. 아직 검증하지 못한 것

- 3-Tier에서 앱이 뜨는지(Flyway 실행, 보관함 값 읽기, 헬스체크). 리허설은 DB 접속과 데이터 조회까지만 했다.
- ALB 주소로 직접 접속이 되는지, 대상 그룹이 healthy 2대인지.
- VPN 터널과 레플리카 복제. UDP 500/4500이 최종 VM에서 통과하는지는 터널을 올려 봐야 안다.
- 스냅샷을 쓰기 중단 전에 떴는지 후에 떴는지(데이터 공백). P2 확인 필요.
