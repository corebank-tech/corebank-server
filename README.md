# Corebank

Corebank 프로젝트는 Spring Boot 기반의 백엔드 애플리케이션입니다.

## 🛠 Tech Stack & Versions

- **Language**: Java 21
- **Framework**: Spring Boot 4.0.7
- **Build Tool**: Gradle
- **Dependencies**:
  - Spring Web MVC (spring-boot-starter-webmvc)
  - Lombok (org.projectlombok:lombok)
  - Spring Boot DevTools (spring-boot-devtools)
  - JUnit Platform (Test)

## 🚀 Getting Started

### Prerequisites
- Java 21 이상
- Gradle

### Build
```bash
# 프로젝트 빌드
./gradlew build
```

### Run
```bash
# 애플리케이션 실행
./gradlew bootRun
```

### Test
```bash
# 테스트 코드 실행
./gradlew test
```
